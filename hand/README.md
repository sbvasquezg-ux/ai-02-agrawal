# Verificación a mano pendiente

La estudiante debe añadir aquí su propia foto manuscrita. No se genera ni se
simula evidencia manual. La comprobación recomendada es derivar

$$
\frac{d}{d\theta}\operatorname{Var}(V(\theta))
=a_0+2\theta\operatorname{Var}(\Gamma/s)
$$

y comprobar que la condición (30) implica \(a_0<0\), pero no implica
\(a_0+2\operatorname{Var}(\Gamma/s)>0\). Esa es la verificación que sustenta
el slip documentado.
